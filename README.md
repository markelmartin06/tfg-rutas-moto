# tfg-rutas-moto

Trabajo de Fin de Grado del ciclo de **Desarrollo de Aplicaciones Web (DAW)**, curso 2026-27.

## Idea

Una aplicación web para moteros, al estilo de Strava pero pensada para rutas en moto: registrar, guardar y compartir rutas, verlas sobre un mapa y descubrir las de otros usuarios.

## Tecnologías previstas

- **Backend:** PHP con Laravel
- **Frontend:** JavaScript
- **Mapas:** Leaflet con OpenStreetMap

El stack puede ajustarse a medida que avance el proyecto.

## Estado

🚧 En fase de propuesta. El desarrollo empieza desde cero.

Entrega final prevista: **mayo de 2027**.
